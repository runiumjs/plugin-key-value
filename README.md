# @runium/plugin-key-value

[![npm](https://img.shields.io/npm/v/@runium/plugin-key-value)](https://www.npmjs.com/package/@runium/plugin-key-value)
[![license](https://img.shields.io/npm/l/@runium/plugin-key-value)](LICENSE)

Runium plugin for store encrypted key-value pairs and use them via macro.

## Installation

```bash
npm install @runium/plugin-key-value
```

or

```bash
yarn add @runium/plugin-key-value
```
